# Lumen — 越滚越不对劲的网站

> **由 Hy4 制作。**

一个单文件的滚动叙事网页。开头是一间看起来完全正常的 SaaS 公司官网：白色背景、蓝色按钮、产品截图、客户评价、价目表。随着你向下滚动，配色、文字、排版、产品界面、客服气泡甚至浏览器标签页都会一点一点「腐化」，最后变成一部恐怖片里的场景——黑脸、无数只盯着你的眼睛、以及一句不要回头。

## 运行

直接用浏览器打开 `index.html` 即可。推荐 Chrome / Edge 桌面端。

- 无需安装依赖
- 无需本地服务器
- 无需联网（所有图形都是内联 SVG 与 CSS，音效由浏览器实时合成）

## 交互

| 操作 | 效果 |
| --- | --- |
| 向下滚动 | 唯一的剧情推进方式，滚动进度（0 → 1）驱动全部变化 |
| 移动鼠标 | 黑暗中瞳孔、脸的目光与「手电筒」微光跟随光标 |
| 声音：关 / 开 | Web Audio 实时合成低频嗡鸣、噪声与心跳，强度随深度递增；浏览器禁止自动播放，故默认关闭 |
| 闪烁：开 / 关 | 关掉后跳过结尾的一次性惊吓闪屏，适合对强光敏感的人 |
| 回到最上面 | 滚到深处后出现，平滑返回顶部并重置剧情 |

## 腐化阶段

| 进度 | 观感 |
| --- | --- |
| 0 – 22% | 干净的营销官网，看不出任何问题 |
| 22 – 42% | 颜色褪去、字体轻微错位、文案开始出现错别字和乱码、页面完整性读数开始下降 |
| 42 – 62% | 底色转为深灰、卡片倾斜、评价变成求救信息、产品截图里睁开一只眼、客服开始和你说话 |
| 62 – 82% | 近乎全黑、噪点与扫描线、文字大面积腐烂、黑暗里陆续睁开的眼睛、页面完整性趋近于 0 |
| 82 – 100% | 正文淡出，巨大的脸从黑暗中逼近，瞳孔跟随光标，一次性惊吓闪屏，以及页面最底下等着你的那句话 |

## 实现要点

- **单一进度量**：`scrollY / (scrollHeight - innerHeight)` 经缓动后写入 CSS 变量 `--p`，再由它派生 `--dark / --eyes / --face / --bodyfade`。
- **调色板插值**：5 组关键帧颜色按进度做 RGB 线性插值，实现从亮白 → 米灰 → 深褐 → 血红 → 纯黑的连续过渡。
- **确定性文字腐化**：用带 seed 与 tick 的哈希决定是否把字符替换成故障符号，所以文字是「逐渐烂掉」而不是每帧乱跳；另有按阶段替换的叙事文案。
- **纯前端绘制**：产品仪表盘、22 只眼睛、最终的人脸、噪点、暗角、血迹全部是 CSS / 内联 SVG；favicon 与页面标题也随进度动态改写。
- **声音合成**：低频振荡器 + 滤波白噪声 + 心跳包络，无任何音频文件。

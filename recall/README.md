# RECALL

一个假的产品官网。前半段是干净的记忆助理 SaaS 落地页，越往下滚越不对劲，最后一屏不给回头路。

> 本项目的设计与实现由 **deepseek4.1f** 完成。

---

## 打开方式

双击 `index.html`，或者：

```bash
npx serve .
```

纯静态，无依赖、无构建、无网络请求。字体全部走系统栈。

---

## 结构

```
recall/
├── index.html    页面结构：14 个滚动区块 + 终局固定层
├── style.css     全部样式，滚动进度的视觉表现都写在 CSS 变量里
└── app.js        滚动引擎：调色板插值、区块进度、遥测数据、终局时间轴
```

三个文件，加起来不到 65 KB。

## 它是怎么烂下去的

整条体验由一条滚动进度 `p`（0 → 1）驱动，其余全是从它派生出来的。

### 颜色

`app.js` 里有一张 `STOPS` 表，11 个关键帧，每帧给出背景、前景、强调、次要四个 RGB 值。每帧按 `p` 在当前区间里做线性插值，写回 CSS 变量。

底色从 `#fbfbf9` 一路走到纯黑，中间会经过一段暖灰的尸白色。在 `p ≈ 0.59` 附近，前景色和背景色会短暂地接近同一个亮度，文字几乎消失。这个"看不见"的时刻刚好落在一整屏空白上。

### 区块进度

每个 `section` 带一个 `data-track`，决定它的局部进度 `--lp` 怎么算：

| 值 | 含义 |
|---|---|
| `exit` | 从顶部滚出视口，0 → 1 |
| `hold` | 顶部到达 35% 视口高时即完成 |
| `enter` | 顶部从视口底走到视口顶 |
| `full`（默认） | 完整穿过视口 |

局部进度写在元素上，子元素通过继承拿到，CSS 里用 `calc()` + `min/max` 做 clamp。所以大部分动画不需要 JS 参与。

### 真实的侵入

第 6、7 屏不是文案，是现场读出来的：

- 当前时间、页面打开时长、已滚动距离
- 设备名、视口尺寸、系统语言、时区（从 `navigator` 和 `Intl` 解）
- 指针最后停在哪（百分比坐标，实时更新）
- 阅读速度（过去几帧的滚动速度取平均）
- 访问次数（`localStorage`，刷新后真的会 +1）

记忆计数从 `4,892,104,331` 开始实时递增，滚得越快涨得越快。

### 索引流

第 11 屏的记忆条目由 JS 生成，26 条递减编号 + 2 条特殊条目，整列随滚动向上流动，最后停在一条红色的记录上：`来源：你 · 状态：永远`。

### 终局

滚过 `p ≈ 0.86` 之后，一层纯黑幕封死页面，往回滚也回不去。之后是一只眼睛，瞳孔跟随鼠标；鼠标静止两秒后它开始自己缓慢漂移。

到底之后等 2.8 秒，会有一次很短的闪白和眼睛猛地凑近。之后如果继续往上滚，屏幕只剩一句话，再滚到顶，只剩两个字：`刷新。`

## 一些实现上的取舍

**不用 IntersectionObserver。** 每帧一次批量 `getBoundingClientRect` 读取、再统一写入，避免 layout thrash。十五个元素，一帧一次排版，够用。

**颜色在 JS 里插值，不在 CSS。** `color-mix()` 做不了多段插值，而且每帧重算一遍 CSS 颜色函数比直接写 `rgb()` 字符串慢。

**文字动画靠 `opacity` 和 `transform` 的 `calc()` 表达式。** 不产生 transition，滚动即停即走，没有滞后感。

**音频要用户先点一下。** 浏览器不让自动播放。第一次点击、按键或触摸页面时会启动一组 55 Hz 的低频嗡鸣，音量随进度上升，峰值非常小，安静的时候才听得见。

## 想改的话

- 文案：直接改 `index.html`。中文标题的换行都是手动 `<br>` 控制的，不用 `text-wrap: balance`，那个对中文断行不可控。
- 颜色走向：改 `app.js` 顶部的 `STOPS`。
- 节奏：改各个 `data-track` 的值，或者调 `style.css` 里 section 的 padding。
- 终局时间轴：`app.js` 主循环里"终局"那一段，所有 `seg(p, a, b)` 的 a、b 就是时间点。

## 兼容性

Chrome / Edge / Safari / Firefox 现代版本。用到了 `color-mix()`、`mask`、`clip-path`、`backdrop-filter`，都是 2023 年之后稳定可用的。

移动端会简化布局，但整条叙事保持不变。`prefers-reduced-motion` 下会关掉装饰性的循环动画。
